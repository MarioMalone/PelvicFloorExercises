语音引导资源目录
================

训练页在「语音引导」开关开启后，会在收缩 / 放松切换时播放以下两个提示音：

  - hold.mp3   对应「收」（开始收缩时播放）
  - relax.mp3  对应「放」（开始放松时播放）

使用说明
--------
1. 请自行准备两个短音频文件（建议 0.5~1 秒、清晰人声「收」「放」），
   命名为 hold.mp3 与 relax.mp3，放入本目录（assets/audio/）。
2. 文件缺失或解码失败时，程序会自动静默降级（仅震动 + 视觉引导），不会崩溃。
3. 若不想提供语音，保持开关关闭即可，App 仍可用震动 + 圆环进度引导。

注意：微信小程序不支持内置 TTS，因此语音必须以音频文件形式提供。
